چهار قدم ساده

Four Simple Steps

1

توکن بات را بگیر

Get a bot token

  1. در تلگرام به @BotFather پیام بده
  2. دستور /newbot را بفرست و یک نام و نام‌کاربری انتخاب کن
  3. توکن را کپی کن (چیزی مثل 123456:ABC...)
  1. Open @BotFather in Telegram
  2. Send /newbot and pick a name + username
  3. Copy the token (looks like 123456:ABC...)
2

کلید رایگان Gemini را بساز

Create a free Gemini key

  1. وارد aistudio.google.com/apikey شو
  2. روی Create API key بزن
  3. کلید را کپی کن — هیچ هزینه‌ای ندارد، سهمیه رایگان هر روز پر می‌شود
  1. Open aistudio.google.com/apikey
  2. Click Create API key
  3. Copy it — it's free, and the free daily quota refills every day
3

با یک کلیک Deploy کن

Deploy with one click

  1. روی دکمه آبی «Deploy» بالای صفحه بزن
  2. اکانت رایگان Cloudflare و GitHub را متصل کن
  3. وقتی خواست، این دو مقدار را بگذار: BOT_TOKEN و GEMINI_API_KEY
  1. Click the orange Deploy button at the top
  2. Connect your free Cloudflare and GitHub accounts
  3. When prompted, enter BOT_TOKEN and GEMINI_API_KEY
4

بات را به خودت قفل کن

Lock the bot to yourself

  1. بعد از Deploy، آدرس وورکر را یک بار در مرورگر باز کن تا وب‌هوک ثبت شود
  2. بات را در تلگرام باز کن و هر پیامی بفرست — شناسه چت تو را می‌گوید
  3. در Cloudflare → کارگر خودت → Settings → Variables and Secrets مقدار ALLOWED_CHAT_ID را اضافه کن
  1. After deploying, open your worker URL once in a browser (registers the webhook)
  2. Open the bot in Telegram and send any message — it replies with your chat ID
  3. In Cloudflare → your worker → Settings → Variables and Secrets, add ALLOWED_CHAT_ID

🎉 تمام شد! حالا یک ویس بفرست و متنش را تحویل بگیر.

🎉 Done! Send a voice message and get the text back.

چطور کار می‌کند؟

How it works

🎙️ ویس شما←☁️ وورکر رایگان کلادفلر←🧠 جمنای گوگل←📝 متن
🎙️ Your voice→☁️ Free Cloudflare Worker→🧠 Google Gemini→📝 Text

صدا هرگز روی سرور ذخیره نمی‌شود؛ فقط برای لحظه‌ای به گوگل ارسال می‌شود تا متن شود و بلافاصله حذف می‌گردد.

Audio is never stored — it's sent to Google for a moment to get transcribed, then discarded.

سؤال‌های رایج

FAQ

بات اصلاً جواب نمی‌دهد. چه کار کنم؟

آدرس وورکر خودت را یک بار در مرورگر باز کن — وب‌هوک به‌صورت خودکار ثبت می‌شود و صفحه وضعیت باید برای هر سه مورد ✅ نشان دهد. اگر چیزی ❌ بود، همان مقدار را در Settings → Variables and Secrets اضافه کن.

Open your worker URL once in a browser — the webhook registers automatically and the status page should show ✅ for all three. If something is ❌, add it under Settings → Variables and Secrets.

چرا شناسه چت من چیز عجیبی است؟

هر چت در تلگرام یک شماره یکتای عددی دارد؛ بات در حالت راه‌اندازی همان را برایت می‌نویسد. آن را بدون تغییر کپی کن.

Every Telegram chat has a unique numeric ID. The bot prints yours in setup mode — copy it exactly.

چطور دیگران هم بتوانند استفاده کنند؟

مقدار ALLOWED_CHAT_ID را با چند شناسه با ویرگول جدا کن، یا متغیر PUBLIC_BOT را روی true بگذار (توجه: سهمیه جمنای خودت مصرف می‌شود).

Add more chat IDs to ALLOWED_CHAT_ID (comma-separated), or set PUBLIC_BOT to true (note: it uses your Gemini quota).

پیام «محدودیت گوگل» می‌آید. چیزی خراب است؟

نه؛ فقط سهمیه رایگان لحظه‌ای پر شده است. چند دقیقه (یا تا فردا) صبر کن — هر روز دوباره پر می‌شود.

No — you just hit the free momentary quota. Wait a few minutes (or until tomorrow); it refills daily.

در ایران بدون فیلترشکن کار می‌کند؟

بدنه بات روی کلادفلر اجرا می‌شود و به گوگل از سمت کلادفلر متصل می‌شود، پس نیازی نیست شبکه تو مستقیماً به گوگل برسد. اگر دامنه workers.dev در شبکه تو مسدود بود، یک دامنه شخصی به وورکر وصل کن.

The worker runs on Cloudflare and calls Google from Cloudflare's side, so your network doesn't touch Google directly. If workers.dev is blocked on your network, attach a custom domain to the worker.
