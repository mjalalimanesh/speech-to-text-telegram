شش قدم ساده

Six Simple Steps

توکن بات را بگیر

Get a bot token

  1. در تلگرام به @BotFather پیام بده
  2. دستور /newbot را بفرست و یک نام و نام‌کاربری انتخاب کن
  3. توکن را کپی کن (چیزی مثل 123456:ABC...)
  1. Open @BotFather in Telegram
  2. Send /newbot and pick a name + username
  3. Copy the token (looks like 123456:ABC...)

کلید رایگان Gemini را بساز

Create a free Gemini key

  1. وارد aistudio.google.com/apikey شو
  2. روی Create API key بزن
  3. کلید را کپی کن — سهمیه رایگان هر روز پر می‌شود
  1. Open aistudio.google.com/apikey
  2. Click Create API key
  3. Copy it — the free daily quota refills every day
⚠️ اگر صفحه کلید ۴۰۳ یا «Access denied» داد، از یک VPN قوی‌تر استفاده کنید. ⚠️ If the page shows 403 / "Access denied", use a stronger VPN.

شناسه چتت را بگیر

Get your chat ID

  1. در تلگرام به @userinfobot پیام بده
  2. دستور /start را بفرست
  3. شناسه عددی خودت را کپی کن (چیزی مثل 123456789)
  1. Message @userinfobot in Telegram
  2. Send /start
  3. Copy your numeric chat ID (looks like 123456789)
💡 این شناسه در قدم آخر لازم می‌شود تا بات فقط برای تو باشد. 💡 You'll need this in the last step to lock the bot to yourself.

یک کپی از کد بساز (Use this template)

Make a copy of the code (Use this template)

  1. اگر حساب GitHub نداری، یک حساب رایگان بساز — github.com → Sign up
  2. این لینک را باز کن: Use this template — صفحه ساخت ریپوی جدید با همین کد باز می‌شود
  3. یک نام دلخواه بگذار (مثلاً my-voice-bot) و Create repository را بزن
  1. If you don't have GitHub, create a free account — github.com → Sign up
  2. Open this link: Use this template — it opens the create-repo page with this code pre-filled
  3. Give it a name (e.g. my-voice-bot) and click Create repository

در Cloudflare دیپلوی کن

Deploy in Cloudflare

  1. وارد dash.cloudflare.com شو (حساب رایگان)
  2. به صفحه Workers & Pages برو
  3. روی Create application بزن و Import an existing Git repository را انتخاب کن
  4. اتصال GitHub را بزن و ریپویی که در قدم قبل ساختی را انتخاب کن
  5. Deploy بزن
  1. Open dash.cloudflare.com (free account)
  2. Go to the Workers & Pages page
  3. Click Create application, then choose Import an existing Git repository
  4. Connect GitHub and choose the repo you created in the previous step
  5. Click Deploy

سه مقدار را اضافه کن و روشنش کن

Add three values and turn it on

  1. در Cloudflare → وورکر خودت → Settings → Variables and Secrets
  2. این سه مقدار را پر کن: BOT_TOKEN (قدم ۱)، GEMINI_API_KEY (قدم ۲)، ALLOWED_CHAT_ID (شماره قدم ۳) — روی هرکدام Edit بزن و مقدار را بچسبان
  3. Deploy بزن
  4. به صفحه اصلی وورکر برگرد (Workers & Pages → نام وورکرت) — دکمه Visit همان بالای صفحه است؛ یک بار بزن
  5. حالا یک ویس بفرست — متنش را تحویل بگیر 🎉
💡 دکمه Visit را پیدا نکردی؟ در Workers & Pages روی نام وورکرت بزن و آدرس https://اسم-وورکر.xxxx.workers.dev را که بالای صفحه نوشته شده در یک تب جدید باز کن — همان کار Visit را می‌کند. 💡 Can't find Visit? In Workers & Pages click your worker's name, then open the URL shown at the top (https://your-worker.xxxx.workers.dev) in a new tab — it does the same thing as Visit.
  1. In Cloudflare → your worker → Settings → Variables and Secrets
  2. Fill these three: BOT_TOKEN (step 1), GEMINI_API_KEY (step 2), ALLOWED_CHAT_ID (step 3) — click Edit on each and paste the value
  3. Click Deploy
  4. Go back to your worker's main page (Workers & Pages → your worker) — click Visit at the top once
  5. Now send a voice message and get the text back 🎉

🎉 تمام شد! حالا یک ویس بفرست و متنش را تحویل بگیر.

سؤال‌های رایج

FAQ

چطور قبل از انتشار، کل فرایند را تست کنم؟

اگر می‌خواهی دقیقاً همان چیزی را ببینی که یک کاربر جدید می‌بیند: در حالت ناشناس مرورگر (یا یک پروفایل دیگر)، یک حساب GitHub تازه و یک حساب Cloudflare تازه بساز و دقیقاً مراحل بالا را انجام بده: «Use this template» → دیپلوی از ریپوی موجود → دکمه Visit → پیام به بات → تنظیم ALLOWED_CHAT_ID → ارسال ویس. این تست در حساب‌های آزمایشی انجام می‌شود و به بات اصلی تو کاری ندارد.

To see exactly what a new user sees: in a private/incognito browser window (or another profile), create a fresh GitHub account and a fresh Cloudflare account, then follow the steps above exactly: "Use this template" → deploy from your existing repo → click Visit → message the bot → set ALLOWED_CHAT_ID → send a voice note. This test runs on the throwaway accounts and doesn't touch your real bot.

دکمه نارنجی Deploy برای من خطا می‌دهد

دکمه نارنجی فقط یک میانبر است؛ بیشتر وقت‌ها کار می‌کند اما بعضی وقت‌ها Cloudflare نمی‌تواند ریپو بسازد (مخصوصاً اگر صاحب ریپوی اصلی هستی). اگر خطا گرفت، اصلاً به دکمه کار نداشته باش و مراحل ۳ تا ۵ بالا را دنبال کن: یک کپی با «Use this template» بساز و بعد از ریپوی خودت دیپلوی کن — همان نتیجه، بدون اینکه Cloudflare ریپویی بسازد.

The orange button is just a shortcut; it usually works, but sometimes Cloudflare can't create the repo (especially if you're the owner of the original repo). If it errors, ignore the button entirely and follow steps 3–5 above: make a copy with "Use this template", then deploy from your own repo — same result, without Cloudflare creating any repo.

بات جواب نمی‌دهد. چه کار کنم؟

در Cloudflare روی دکمه «Visit» بزن تا بات روشن شود (فقط یک بار لازم است). اگر باز هم جواب نداد، صفحه وضعیت را ببین؛ هر چیزی ❌ بود، همان مقدار را در Settings → Variables and Secrets اضافه کن.

Click "Visit" in Cloudflare to turn the bot on (only needed once). If it still doesn't answer, check the status page; anything ❌ → add it under Settings → Variables and Secrets.

/claim چیست و بهش نیاز دارم؟

در مسیر پیش‌فرض به /claim نیاز نداری — بات با ALLOWED_CHAT_ID فقط برای توست. /claim مخصوص کاربران پیشرفته است که binding کی‌وی OWNER_STORE را دستی اضافه کنند (آن‌وقت اولین نفر صاحب بات می‌شود). اگر از آن استفاده نمی‌کنی، کاملاً نادیده بگیر.

You don't need /claim in the default path — ALLOWED_CHAT_ID already locks the bot to you. /claim is for advanced users who add the OWNER_STORE KV binding manually (then the first sender owns the bot). If you don't use it, just ignore it.

چطور دیگران هم بتوانند استفاده کنند؟

متغیر PUBLIC_BOT را روی true بگذار تا هر کسی بتواند استفاده کند (با سقف روزانه پیش‌فرض ۲۰ پیام برای هر چت). توجه: سهمیه جمنای خودت مصرف می‌شود.

Set PUBLIC_BOT to true to let anyone use it (default daily cap of 20 messages per chat). Note: it uses your Gemini quota.

پیام «محدودیت گوگل» می‌آید. چیزی خراب است؟

نه؛ فقط سهمیه رایگان لحظه‌ای پر شده است. چند دقیقه (یا تا فردا) صبر کن — هر روز دوباره پر می‌شود.

No — you just hit the free momentary quota. Wait a few minutes (or until tomorrow); it refills daily.

در ایران بدون فیلترشکن کار می‌کند؟

بدنه بات روی کلادفلر اجرا می‌شود و به گوگل از سمت کلادفلر متصل می‌شود، پس نیازی نیست شبکه تو مستقیماً به گوگل برسد. اگر دامنه workers.dev در شبکه تو مسدود بود، یک دامنه شخصی به وورکر وصل کن. برای ساخت کلید در AI Studio اگر خطای ۴۰۳ یا «Access denied» دیدی، از یک VPN قوی‌تر استفاده کن.

The worker runs on Cloudflare and calls Google from Cloudflare's side, so your network doesn't touch Google directly. If workers.dev is blocked on your network, attach a custom domain to the worker. If AI Studio shows 403 / "Access denied" when creating a key, use a stronger VPN.
